# 关口争夺 · 八卦战场

《关口争夺》是玩家与大模型对战的策略游戏，纯浏览器运行。你指挥蓝方，接入的模型指挥红方。

**在线游玩：** <https://beyondstand.github.io/passline/>

## 开始对战

1. 打开游戏页面。首页按后天方位排列八卦关卡，选中一个卦位可预览实战地形和元素规则，再点击「进入关卡」。
2. 填入服务商提供的 API 基础地址或完整的 `/chat/completions` 地址，以及准确的模型 ID。需要鉴权的接口同时填写 API 密钥。点击「测试连接」后可开始对战。
3. 选关页和战场顶部都有「玩法说明」，包含回合操作、胜负条件和当前所选关卡的元素规则。

对局期间点击「返回选关」可查看其他地图。点击「返回对局」继续当前游戏。选择其他关卡后点击「在此关开新局」，可沿用当前模型配置开局。

游戏全部在浏览器本地运行，无需任何服务器；刷新页面会结束当前对局，重新开局即可。

## 一个回合怎么玩

- **侦察下令。** 点选起点与目标后确认，或从己方据点拖拽出兵。预设部队同步启程。每轮可花 1 点侦察一个邻接据点。
- **即时行军。** 抵达后即时交战或增援。普通相邻路径每段基准 5 秒，连通的己方道路每段基准 1.5 秒。双方各可临时追加一次出兵。行军到第 3 秒会等模型完成增援决策，元素和行军计时一同暂停。
- **结算建设。** 每 1 点可在己方指挥部或中央关口征募 3 兵，或在两座邻接的己方据点之间修一段路。轮末净新占的基地奖励 1 点，控制的基地在下轮各提供 1 点。
- **获胜。** 连续两个轮末控制中央关口，或在轮末占领对方指挥部。双方同轮达成时判为平局。

## 八卦关卡

卦名、符号、自然物象、五行和后天方位取自传统八卦表。地图、关名与规则为游戏原创。

| 卦与物象 | 关卡与路线 | 关卡元素 |
| --- | --- | --- |
| ☰ 乾 · 天 | 云阙天门，双层浮岛可绕下层中继 | 每 4 秒交替云开与云合。云开时双方可见所有在途兵力。 |
| ☷ 坤 · 地 | 厚土原，三层梯田可横向互援 | 每 5 秒交替开启地脉。开启时，标记据点的驻军获 2 点屏障。 |
| ☳ 震 · 雷 | 惊雷原，斜向雷环夹着两处雷眼 | 每 5 秒劈中雷眼，标记据点驻军 −2。 |
| ☴ 巽 · 风 | 回风峡，S 形峡谷有对角线直攻与弯道侧翼 | 每 4 秒换向，顺风 ×1.5，逆风 ×0.65。在途即时变速，下一轮交换起始顺风方。 |
| ☵ 坎 · 水 | 双潮河，三汊河口可选高堤或快渡 | 每 5 秒涨退潮，标记渡线低潮 ×1.4、涨潮 ×0.5。 |
| ☲ 离 · 火 | 赤焰谷，环脊绕行或由南坡攻入火山口 | 余烬与明火每 4 秒切换。明火期抵达标记据点的部队先损失 1 兵。 |
| ☶ 艮 · 山 | 叠嶂隘，沿对角山脊争夺两侧峰哨 | 每 3 秒开闭山道，落石时暂停通过标记路径新出兵。 |
| ☱ 兑 · 泽 | 映泽洲，两条月弧绕向可补兵的泽岛 | 每 6 秒给已被控制的标记泽地各补 1 兵。 |

进度条显示当前元素、离下一次变化的时间和作用对象。模型读取同一份进度，还能读取按元素计算的预计抵达时间。同刻发生的落雷或泽泉先于抵达结算。选关菜单也可进入风门关经典地图。

## 模型接口

支持 OpenAI 兼容的 [Chat Completions](https://developers.openai.com/api/reference/resources/chat) 接口，使用普通 JSON 请求和回复。本地模型若支持该接口，也可填入它的 HTTP 地址。模型每回合处理下令、增援和建设，选择侦察时会再请求一次决策。配置的服务商按自己的规则计费。

模型默认请求最高推理档。应用按 `max`、`xhigh`、`high`、`medium`、`low`、`minimal` 的顺序处理接口对推理档位的明确拒绝，并复用本局已协商的值。接口明确拒绝强度参数时使用其默认配置。连接结果显示应用请求的档位。[OpenAI 推理档位](https://developers.openai.com/api/docs/guides/reasoning) · [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)

### 与本地版的差异

- **密钥保存在浏览器 localStorage。** API 地址、模型名和密钥自动保存在你本机浏览器中，密钥以明文形式留在浏览器存储里（不用于任何其他用途）。换浏览器或设备需重新填写。可在设置中点击「移除已保存密钥」删除记录。
- **浏览器直连模型 API。** 请求从你的浏览器直接发往你配置的服务商。OpenAI 等主流服务商支持浏览器跨域调用；个别服务商禁止浏览器直连（CORS 限制），这类接口在网页版无法使用。
- **建议使用较新的浏览器。** Chrome/Edge 116+、Safari 17.4+、Firefox 124+。

如果请求失败，游戏会显示错误并保留当前阶段，支持重试模型。对局中也可打开「API 设置」修改地址、模型或密钥，再点击「应用到本局」。保存的密钥只会复用于原 API 地址。
